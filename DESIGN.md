# Design System — دَوَّنلي

> **Daftar** (دفتر — "notebook"). Warm paper + ink + a calm green, and four
> colored "worlds" that each own one domain of the app. RTL-first.
>
> Generated by scanning `web/style.css`. All values below are the literal
> tokens in use — this document describes what the code already does, it does
> not prescribe anything new.

---

## 1. Foundations

### Surfaces & ink

| Token | Value | Role |
|---|---|---|
| `--paper` | `#F6F1E4` | App background |
| `--paper-deep` | `#EFE8D6` | Recessed paper |
| `--surface-card` | `#FFFCF5` | Card / field background |
| `--surface-raised` | `#FFFFFF` | Raised surface |
| `--ink` | `#34302A` | Primary text |
| `--ink-muted` | `#6E665A` | Secondary text |
| `--ink-faint` | `#9A9082` | Placeholder, meta text |
| `--hairline` | `#DFD7C4` | Subtle divider |
| `--hairline-strong` | `#C9BFA8` | Field border |

The body carries `--paper-grain`, a 3.5%-opacity `feTurbulence` fractal-noise
data-URI tiled at 160px. This is the single texture that makes the app read as
paper. Do not add a second grain layer.

### The four worlds

Each domain owns a hue, used on its buttons, chart bars, and tints. This is the
app's main navigation signal — do not introduce a fifth world color.

| World | Base | Deep | Tint | Wash |
|---|---|---|---|---|
| Health (الصحة) | `#E0705C` | `#C4543F` | `#F6D5CD` | `#FBEAE5` |
| Habits (العادات) | `#E3A24A` | `#C07F25` | `#F6E1BE` | `#FBF0D9` |
| Goals (الأهداف) | `#5285A6` | `#3A647F` | `#C3DAE7` | `#E3EEF4` |
| Finances (الفلوس) | `#6FA84A` | `#527F35` | `#CFE3BD` | `#EAF2E1` |

Two later modules reuse the same three-step structure: **ideas** `#7C6BC9` and
**problems** `#D06A8C`. Brand green is `#5C8A6B` (deep `#426B52`), and coin gold
is `#C9962E`.

Status: `--success` `#6FA84A`, `--warning` `#E3A24A`, `--danger` `#E0705C`
(deep `#C4543F`).

### Typography

Two families, deliberately contrasted: **Lemonada** (geometric, slightly
hand-drawn) for display, **Tajawal** (humanist) for body. Same weight range,
opposite skeletons — so they never blur together.

```
--font-display: "Lemonada", "Tajawal", system-ui, sans-serif;
--font-body:    "Tajawal", "Lemonada", system-ui, sans-serif;
```

Scale (rem): `--text-display` 3.5 · `--text-h1` 2.5 · `--text-h2` 2 ·
`--text-h3` 1.5 · `--text-h4` 1.25 · `--text-lg` 1.125 · `--text-base` 1 ·
`--text-sm` 0.875 · `--text-xs` 0.75

Composite shorthands: `--type-h1/h2` (700, 1.2), `--type-h3` (500, 1.4),
`--type-body` (400, 1.7), `--type-lead` (400/1.7 at `--text-lg`),
`--type-label` (700, 0.875/1.4). Always use a shorthand; never hand-roll
`font:` for a new element.

### Spacing, radii, elevation

`--space-1..8` = 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px.

Radii: `--radius-sm` 14 · `--radius-md` 20 · `--radius-lg` 28 ·
`--radius-pill` 999. The signature pair:

```
--radius-sketch:   255px 15px 225px 15px / 15px 225px 15px 255px;
--radius-sketch-2: 15px 225px 15px 255px / 255px 15px 225px 15px;
```

These asymmetric four-corner radii are what make `.sketch-box` and
`.card.sketch` look hand-drawn. Use them; do not replace with a uniform radius.

Elevation is paper-stack, not glass — warm-tinted `rgba(52,48,42,…)`:
`--shadow-sm` `0 2px 8px/.06` · `--shadow-md` `0 4px 16px/.08` ·
`--shadow-lg` `0 10px 30px/.12` · `--shadow-press` `0 1px 4px/.10`.
`--stroke: 2px` is the standard hand-drawn border weight.

Note the codebase's own rule: sketch boxes deliberately pair a `2px` ink border
with `--shadow-md`. Keep border **or** heavy shadow, never both heavy.

### Motion

`--ease-pen` `cubic-bezier(.65,0,.35,1)` for pen-like draws ·
`--ease-soft` `cubic-bezier(.33,1,.68,1)` as the default ·
`--ease-bounce` `cubic-bezier(.34,1.56,.64,1)` reserved for playful taps.
Durations: `--dur-fast` 160 · `--dur-base` 280 · `--dur-slow` 600 ·
`--dur-draw` 1200ms.

Bounce is the one non-exponential curve and it is rationed — don't spread it.

Every animation has a `prefers-reduced-motion` kill switch (three currently:
`.view-fade`, `.rec-dot`/`.rec-wave`, `.upd-progress`). **Any new animation
needs a matching reduced-motion rule.**

## 2. Layout

`html { direction: rtl }` — logical properties (`inset-inline`,
`margin-inline`) are mandatory; physical `left`/`right` is a bug.

Breakpoints: **1000px** and **760px** (also 640px in the updater block).
760px is the main one — it collapses cards to `padding: 14px` and drops
`--text-h3` to `--text-h4`.

The body has a deliberate overflow safety net: `overflow-x: hidden` on `html`
and `body`, with `overflow-wrap` on text containers, so a long unbroken token
(saudi-eg URL, raw number) can never shove the RTL layout sideways.

Safe-area insets are respected for the bottom nav and mic button via
`env(safe-area-inset-bottom)`.

## 3. Components

### Fields

```css
.field {
  font: var(--type-body);
  color: var(--ink);
  background: var(--surface-card);
  border: 1.5px solid var(--hairline-strong);
  border-radius: var(--radius-sm);
  padding: 10px 14px;
  min-width: 0;
}
.field:focus { border-color: var(--brand); }
```

`min-width: 0` is load-bearing — it lets fields shrink inside flex rows instead
of forcing overflow. `.field::placeholder` uses `--ink-faint`. Forms are
`.inline-form` (`flex-wrap: wrap; gap: 10px; align-items: center`) with an
optional `.grow` (`flex: 1; min-width: 140px`) for the note field.

Native controls reuse `.field` wholesale — `select.field` only adds
`cursor: pointer`. **A native `input[type=date]` gets the class and nothing
else**; do not rebuild it as a custom calendar.

### Buttons

`.btn` — inline-flex, `gap: 8px`, 700 weight, `padding: 12px 22px`,
`border-radius: 18px`. Sizes: `.sm` (`8px 16px` / `--text-sm` / radius-sm),
`.lg`. States: `:hover` lifts `translateY(-1px)` + `--shadow-lg`;
`:active` is `scale(0.97)` + `--shadow-press`; `:disabled` drops to `opacity: 0.5`.

Variants: `.secondary`, `.ghost`, and one color class per world —
`.health .habits .goals .finances .ideas .problems .danger`, each with a
matching `:hover` that steps to the `-deep` tone.

### Cards

`.card` + `.card-head` (flex row, `h3` at `--type-h3`, optional right-side
meta at `--text-sm` muted). `.card.sketch` swaps in the asymmetric radius.

### Squiggle underline

`.squiggle` is an inline-block with a `::after` that paints a hand-drawn
green stroke from an inline SVG data-URI, offset `bottom: -0.3em`. This is the
brand's one decorative flourish — apply to one heading, not many.

## 4. Conventions

- **Numbers are Arabic-Indic.** `arNum()` formats money and counts; all
  finance/health output goes through it.
- **Icon-plus-label pairs.** `CAT_ICONS` / emoji carry category meaning
  alongside the Arabic word — never the emoji alone.
- **Charts are hand-drawn.** `drawSketchBars()` renders bar charts to canvas
  with a sketchy stroke, not a charting library.
- **`web/`, not `public/`.** Static files are served through Express so the
  auth gates on `/app.js` and `/admin.js` cannot be bypassed by a CDN serving
  a directory statically. Do not move it back.
- Fonts load from Google Fonts via `@import` at the top of `style.css`.

## 5. Known gaps

Recorded, not endorsed:

- Google Fonts are render-blocking `@import`s in CSS rather than `<link>` with
  `preconnect`.
- Reduced-motion coverage is per-component and incomplete — there is no global
  blanket rule.
- Contrast of `--ink-faint` (`#9A9082`) on `--surface-card` (`#FFFCF5`) is
  roughly 3.3:1, below the 4.5:1 body-text bar. It's currently used on small
  meta text and placeholders, where it is the weakest link in the system.
- No dark theme. The second `:root`-like block in the stylesheet is a scoped
  `.syntax-banner` theme for a third-party code-highlight widget, not an app
  theme.
